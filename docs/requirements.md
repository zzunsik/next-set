# 요구사항 (v1)

작성일: 2026-11-17. 이슈 [#6](https://github.com/zzunsik/next-set/issues/6).

첫 버전에 넣을 것과 뺄 것을 적는다. 화면과 데이터의 구체적인 모양은 설계 이슈에서 정한다.

## 목적

헬스장에서 근력 운동을 기록하는 Android 앱이다. 세 가지를 지킨다.

- 저장한 루틴을 홈에서 한 번 눌러 시작한다.
- 지난번과 같은 세트는 체크 한 번으로 적는다.
- 서버와 계정 없이 기기 안에서만 동작한다.

## 용어

| 용어 | 뜻 |
|---|---|
| 종목 | 벤치 프레스, 풀업 같은 운동 동작 하나 |
| 세트 | 한 종목을 쉬지 않고 이어서 한 묶음. 무게와 횟수, 횟수, 시간 가운데 하나를 적는다 |
| 루틴 | 종목 목록과 종목별 세트 수, 목표 값을 묶어 저장한 것 |
| 운동 기록 | 한 번 운동하며 적은 세트 전체 |
| 직전 기록 | 같은 종목을 마지막으로 한 운동 기록에서 같은 순번에 있는 세트 |
| 다음 세트 | 진행 중인 운동에서 아직 완료하지 않은 첫 세트 |

## 확인이 남은 항목

설계 이슈에서 정한다. 괄호 안은 초안의 제안이다.

1. 사용자가 맨 위 루틴을 직접 골랐을 때(HOME-03) 그 선택이 언제까지 유지되는가. (그 루틴으로 운동을 마치면 다시 자동 순서로 돌아간다)
2. 휴식 시간의 기본값과 늘리고 줄이는 폭. (기본 2분, 15초씩)
3. 무게가 같은 세트끼리 최고 기록을 가릴 때의 기준. (횟수가 많은 쪽)
4. [정함] 맨몸 종목에 무게를 더해 하는 경우는 기록 방식이 무게와 횟수인 별도 종목으로 둔다. 중량 풀업, 중량 친업, 중량 딥스 세 개를 내장하고 무게 칸에는 더한 무게만 적는다. (반영: EX-01, `docs/exercise-list.md`)
5. 백업 파일을 가져올 때 기존 기록을 지우고 바꾸는가, 합치는가. (확인을 받은 뒤 전체를 바꾼다)
6. 새 기기로 옮길 때 쓰는 기기 간 직접 전송에 앱 데이터를 넣는가. 클라우드를 거치지 않는 전송이다. 지금은 넣지 않게 설정돼 있다.
7. [정함] 휴식 동안만 도는 포그라운드 서비스(종류 `specialUse`)가 소리와 진동을 직접 낸다. 사용자에게 묻는 권한은 알림 하나이고 '알람 및 리마인더' 권한은 받지 않는다. (반영: REST-06, REST-09, `docs/rest-timer.md`)
8. [정함] 붙인다. 버튼은 시간 줄이기, 시간 늘리기, 건너뛰기 3개다. 승격된 알림에서 실제로 어떻게 보이는지는 구현할 때 에뮬레이터로 확인한다. (반영: REST-07, `docs/rest-timer.md`)
9. [정함] 내장 종목은 130개다. 검수에서 고친 종목과 빠진 종목은 없었고, 그 뒤에 중량 종목 3개와 세부 부위를 더했다. (반영: EX-01, `docs/exercise-list.md`)
10. 강조색과 완료 색의 정확한 값. 밝은 화면과 어두운 화면의 대비를 확인해 정한다.
11. 한국에 Android 개발자 인증 의무가 적용될 때의 등록 절차. 2027년 이후 전 세계로 넓힌다고 발표됐다.
